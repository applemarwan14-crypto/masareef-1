# مصاريف البيت

تطبيق ويب عائلي لتسجيل المصاريف الشهرية ومتابعتها بشكل مشترك بين الزوجين: إضافة المصروف في ثوانٍ، لوحة تحكم واضحة، مصاريف ثابتة بحالة دفع، ميزانية شهرية، صور فواتير، وتصدير Excel وPDF. الواجهة عربية بالكامل (RTL) والعملة الريال السعودي.

## التقنيات

| الطبقة | الاختيار | السبب |
|---|---|---|
| الواجهة | React 19 + TypeScript + Vite | سريع، مكتوب بأنواع صارمة، يُنشر كموقع ثابت على GitHub Pages |
| التصميم | Tailwind CSS 4 + خط IBM Plex Sans Arabic | RTL أصيل، وضع داكن تلقائي |
| البيانات | TanStack Query | تخزين مؤقت، تحديث تلقائي، حالات التحميل والأخطاء |
| الخادم | Supabase (PostgreSQL + Auth + Realtime + Storage) | قاعدة بيانات حقيقية، حسابات آمنة، تحديث لحظي، تخزين خاص للفواتير، وخطة مجانية كافية لعائلة |
| مكونات | vaul (لوحات سفلية للجوال)، sonner (تنبيهات)، Phosphor Icons (أيقونات)، Motion (حركات)، Recharts (رسوم بيانية) | مكتبات مفتوحة المصدر موثوقة بدلاً من بنائها من الصفر |
| تصدير | ExcelJS (يُحمَّل عند الطلب فقط)، وطباعة المتصفح لـ PDF | PDF عبر المتصفح يعرض الحروف العربية متصلة بشكل صحيح |
| اختبارات | Vitest | اختبارات للحسابات والتواريخ والمصاريف المتكررة |

## الإعداد (مرة واحدة، حوالي 10 دقائق)

### 1. إنشاء مشروع Supabase
1. أنشئ حساباً مجانياً في [supabase.com](https://supabase.com) ثم مشروعاً جديداً (اختر منطقة قريبة).
2. افتح **SQL Editor**، والصق محتوى الملف `supabase/migrations/0001_init.sql` كاملاً، ثم **Run**.
3. من **Authentication → URL Configuration** ضع في **Site URL** رابط موقعك على GitHub Pages، مثل `https://USERNAME.github.io/REPO/`.
4. (اختياري) من **Authentication → Providers → Email** يمكنك إيقاف **Confirm email** إذا أردت الدخول مباشرة دون رسالة تأكيد.
5. من **Project Settings → API** انسخ **Project URL** و **anon public key**.

> مفتاح anon آمن للنشر في الواجهة؛ الحماية الفعلية في سياسات RLS داخل قاعدة البيانات، ولا يستطيع أحد رؤية بيانات عائلتك دون أن يكون عضواً فيها.

### 2. الرفع على GitHub والنشر
1. ارفع المشروع إلى مستودع جديد على GitHub.
2. من **Settings → Secrets and variables → Actions** أضف سرّين:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. من **Settings → Pages** اختر **Source: GitHub Actions**.
4. أي `push` على فرع `main` يشغّل الاختبارات ثم يبني الموقع وينشره تلقائياً.

### 3. أول استخدام
1. افتح الموقع وأنشئ حسابك، ثم اختر **إنشاء عائلة**.
2. من **الإعدادات** انسخ **رمز الدعوة** وأرسله لزوجتك.
3. تنشئ حسابها وتختار **لدي رمز دعوة**. الآن كل عملية يضيفها أحدكما تظهر للآخر فوراً.
4. (اختياري) بعد انضمامكما يمكنك إيقاف التسجيل الجديد من **Authentication → Providers → Email → Allow new users to sign up**.

على الجوال: افتح الموقع في Safari أو Chrome ثم **إضافة إلى الشاشة الرئيسية** ليعمل كتطبيق.

## الإصدار الثاني: رسائل البنك بـ Claude، الرحلات، التجديدات، الإشعارات

### ما الجديد
- **قراءة رسائل البنك بـ Claude:** أي بنك سعودي. يقرأ المبلغ، واسم المتجر بعد تنظيفه، والتاريخ، والبطاقة، وطريقة الدفع، والبنك، والدولة. إذا Claude ما رد يقرأها القارئ المحلي، فما تضيع عملية. يتجاهل رسائل التحقق والمرفوضة والمستردة، ويخفي الرصيد وأرقام الحسابات قبل الإرسال.
- **يتعلّم:** إذا غيّرت تصنيف متجر مرة، يتذكره ويصنّف عليه بعدين. وتقدر تطبّق التغيير على العمليات السابقة.
- **تنظيم التصنيفات بضغطة** مع تراجع كامل. التصنيفات الأساسية مثبّتة 📌.
- **البطاقات والعملات:** كل بطاقة تنحفظ مع نسبة رسومها الدولية، والعملة الأجنبية تتحول للريال بسعر اليوم وتنضاف الرسوم.
- **الإشعارات من التطبيق** (push على الآيفون): مصاريف العائلة، الميزانية عند 80% و100%، موعد الثابتة، ملخص الشهر، رسالة ما انسجلت، الرحلات، التجديدات، الخصم المكرر، وتذكير يومي الساعة 9 الصبح. كلها مفعّلة افتراضياً، وكل شخص يتحكم فيها من الإعدادات.
- **الرحلات:** أول شراء حضوري من خارج السعودية يفتح رحلة، وأول شراء محلي أو 3 أيام بدون مشتريات من برا يقفلها. مصاريفها منفصلة عن ميزانية الشهر.
- **التجديدات والضمانات والتأمين:** من رسائل البنك وأبشر، أو بكتابة عادية (ويفهم الهجري). الأجهزة من 300 ر.س لها ضمان سنتين.
- **قراءات:** متى تصرفون أكثر، أول الشهر بعد الراتب، المدفوعات المتكررة مع زر «للثابتة»، العادات، والأعلى من المعتاد. Claude يكتب الملاحظات، والأرقام محسوبة بدقة.
- **السنوات:** مقارنة عادلة بنفس الأشهر، وأرشفة سنة قديمة (Excel كامل أولاً، بعدها يبقى الملخص).
- **الإدارة:** المنشئ وحده يدير التصنيفات والميزانية والبطاقات والأعضاء.

### خطوات التفعيل (مرة واحدة)
1. **قاعدة البيانات:** من Database → Extensions فعّل `pg_cron` و `pg_net`. بعدها في SQL Editor نفّذ الملفات من `0005` إلى `0016` في `supabase/migrations` **بالترتيب**. ثم نفّذ هذا السطر برابط مشروعك:
   ```sql
   select vault.create_secret('https://xxxx.supabase.co', 'project_url');
   ```
2. **مفاتيح الإشعارات (VAPID):** شغّل الأمر هذا مرة وحدة:
   ```bash
   npx web-push generate-vapid-keys
   ```
3. **أسرار دوال الخادم:** من Edge Functions → Secrets في Supabase أضف:
   - `ANTHROPIC_API_KEY`: مفتاحك من console.anthropic.com
   - `VAPID_PUBLIC_KEY` و `VAPID_PRIVATE_KEY`: من الخطوة 2
   - `VAPID_SUBJECT`: بريدك بالشكل `mailto:you@example.com`
   - (اختياري) `CLAUDE_MODEL`: الافتراضي `claude-opus-5-5`
4. **أسرار GitHub:** أضف `VITE_VAPID_PUBLIC_KEY` (المفتاح العام نفسه)، و `SUPABASE_ACCESS_TOKEN` (من supabase.com/dashboard/account/tokens)، و `SUPABASE_PROJECT_REF` (رمز المشروع من رابطه). بعدها أي `push` على `main` ينشر الموقع والدوال (`sms` و `ai` و `push`) تلقائياً.
5. **اختصار الآيفون:** غيّر رابط الاختصار إلى `https://xxxx.supabase.co/functions/v1/sms` بنفس المتن `{"token", "message"}`، واحذف خطوة إظهار الإشعار منه. الرمز والطريقة كاملة موجودة في الإعدادات ← رسائل البنك.
6. **إشعارات الآيفون:** افتح الموقع في Safari، ثم مشاركة ← إضافة إلى الشاشة الرئيسية. افتحه من الشاشة الرئيسية، وبعدها الإعدادات ← تفعيل إشعارات الجوال (يحتاج iOS 16.4 أو أحدث).

## كيف يعمل

**إضافة مصروف:** زر + في أسفل الشاشة يفتح لوحة فيها حقل المبلغ جاهز للكتابة، ثم ضغطة على التصنيف، ثم «إضافة». التاريخ افتراضياً اليوم، ومن أضاف المصروف يُسجَّل تلقائياً. يقبل الأرقام العربية (١٢٥٫٥) واللاتينية.

**المصاريف الثابتة:** تُعرَّف مرة واحدة (الاسم، المبلغ، يوم الاستحقاق). كل شهر يظهر كل منها «غير مدفوع» أو «متأخر»، وضغطة «تسجيل الدفع» تنشئ عملية حقيقية في السجل. قاعدة البيانات تمنع تسجيل دفعة ثانية لنفس الشهر حتى لو ضغط الزوجان في نفس اللحظة.

**الحسابات:** كل المبالغ تُخزَّن بالهللة كأعداد صحيحة، فلا توجد أخطاء مثل `0.1 + 0.2 = 0.30000000000000004`. النسب المئوية في لوحة التحكم مجموعها 100% دائماً. التواريخ تُحسب بتوقيت الرياض وبالتقويم الميلادي.

## هيكل المشروع

```
supabase/migrations/0001_init.sql   الجداول، القيود، سياسات RLS، الدوال، التخزين
src/
  lib/        منطق خالص قابل للاختبار: money, dates, stats, recurring, export, api
  hooks/      الجلسة، بيانات العائلة، استعلامات TanStack، المزامنة اللحظية
  components/ واجهة مشتركة: Layout، لوحة إضافة المصروف، القوائم، الرسوم
  pages/      الرئيسية، العمليات، الثابتة، الإعدادات، الدخول، الإعداد الأولي
```

## قاعدة البيانات

- `households`: العائلة، الميزانية الشهرية، رمز الدعوة.
- `household_members`: الأعضاء وأدوارهم (مستخدم واحد = عائلة واحدة).
- `categories`: التصنيفات؛ لا تُحذف إن كانت عليها عمليات، بل تُؤرشف حفاظاً على السجل.
- `recurring_expenses`: قوالب المصاريف الثابتة.
- `expenses`: دفتر العمليات؛ كل عملية مرتبطة بتصنيف من نفس العائلة عبر مفتاح أجنبي مركّب.
- `monthly_category_totals`: عرض (View) للإجماليات الشهرية يحترم صلاحيات المستخدم.
- حاوية `receipts` خاصة، والوصول للفواتير بروابط مؤقتة صالحة 10 دقائق.

## الأمان

- سياسات RLS على كل جدول: لا يرى المستخدم إلا بيانات عائلته.
- حقول مثل `household_id` و`created_by` مقفلة بمحفزات فلا يمكن تغييرها بعد الإنشاء.
- لا يمكن للعضو تغيير دوره؛ فقط اسمه المعروض.
- الانضمام للعائلة برمز دعوة يمكن للمنشئ تغييره في أي وقت.
